I've written about my Mac setup before, so here is another computer setup that literally no one asked for. This time it's my old gaming PC, which is now a Linux homeserver.

### Hardware

I'm using my old gaming PC. Nothing bought specifically for this, just giving a computer I already had something else to do.

I don't have a very exciting hardware section for you. It's an old gaming PC running Ubuntu. That's pretty much it xD

### Ubuntu

I went with Ubuntu for the OS. The setup was straightforward and I didn't run into any issues, which makes this part of the post quite short.

Install Ubuntu, get it running, move on to the things I actually wanted to use it for.

### Tailscale

I use Tailscale to access the server. Having a machine running at home is much more useful when I can actually get to it from somewhere else.

This also went smoothly. I was expecting to have something annoying to write about here, but apparently this is a blog post about things working 😄

### T3 Code & AI agents

I'm using the server for T3 Code and AI agents. This is the part that gives the old PC something useful to do.

It's a fairly simple setup: Ubuntu on the old PC, Tailscale for access, and T3 Code and agents as the reason to leave it running.

### Mac backups

I also use it to back up my Mac. It's nice having somewhere to keep a backup, and it's another reason to keep the old PC around.

### Conclusion

That's the homeserver so far. A pretty simple setup, but I'm happy to have a use for the old PC.

If I end up adding more to it, maybe I'll write another post. Although I also said I'd write about my WSL setup, so don't hold me to that.
